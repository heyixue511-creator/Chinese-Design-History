# 故宫博物院藏 高一六·四厘米口径三七·四厘米 新石器时代彩陶几何纹盆

彩陶系指画有黑、红、白、褐等色纹饰的陶器，彩料由白土或含氧化铁和氧化锰等的天然矿物原料加工研磨而成。在成型后的陶坯上用毛笔蘸彩料描画纹饰后入窑经九百摄氏度左右的温度焙烧而成。彩陶上的纹饰见有动物、植物、人物、几何、日月星辰等，画法古朴自然，蕴含人类原始宗教的理念思维，给人以神秘之感。它是中国陶瓷工艺史上最早把装饰纹样与器物结合在一起而创造的艺术品，堪称远古文化艺术的第一个高峰。

此盆外壁三角形纹饰系由具象鱼纹逐渐抽象演变而成，其造型和纹饰均具有新石器时代仰韶文化半坡类型彩陶的显著特征。仰韶文化因一九二一年首次发现于河南省渑池县仰韶村而得名，主要分布在黄河中、下游地区。

考古调查和发掘获得的资料证明，浙江上虞地区至迟在东汉晚期就已能普遍烧造基本符合现代瓷器标准的瓷器。浙江既是瓷器的发源地，也是三国、两晋时期瓷器生产的中心。这一时期的浙江瓷窑除大量烧造精美的青瓷外，还烧造少量黑釉瓷。同时期的江苏、福建、江西、湖南、湖北和四川等省，亦相继设立瓷窑，烧造各具地方特色的瓷器。

此谷仓罐系二十世纪三十年代后期浙江绍兴三国(吴)墓出土。罐上署年款“永安三年”，永安系三国时期吴主孙休的年号，永安三年即公元二六〇年。该器以百鸟争食、欢庆丰收、牲畜满栏等立体雕饰展现了一千七百多年前江南五谷丰登的场景，散发着浓郁的生活气息。

原始瓷出现于夏商之际，系以瓷土作胎，器表施一层透明草木灰釉或石灰釉，入窑经一千两百摄氏度以上温度焙烧而成。其胎质坚硬，器表光亮，但与真正的瓷器相比，在胎体吸水率、机械强度、烧成温度等方面仍带有一定的原始性，故被称作“原始瓷”。西周、春秋、战国、西汉时期，原始瓷产量增加，质量亦不断提高，浙江、江苏、江西、福建、台湾、广东、广西及湖南南部广大地区，均有出土。

此提梁盉造型仿青铜器。青铜提梁盉在中原一般用作实用器兼礼器，而用原始瓷仿青铜礼器随葬，曾是古越人(“越”或“百越”是先秦古籍中对秦代以前生活于长江以南沿海等地的土著部落之统称)丧葬习俗的重要内容之一，是一种特有的文化现象。

唐越窑秘色瓷八棱净瓶文物级别：一级品高二·五厘米 口径一·七厘米足径七·二厘米故宫博物院藏

唐代，瓷器已成为人们日常生活中最重要的生活用器，瓷器生产总体呈现“南青北白”的地域特征，即南方以青瓷为主，北方则以白瓷为主。代表当时最高制瓷工艺水平的是南方主要烧造青瓷的越窑和北方主要烧造白瓷的邢窑。

一九八七年在陕西省扶风县法门寺唐代塔基地宫中曾出土十四件越窑秘色瓷，其中有一件秘色瓷八棱瓶，造型和釉色均与此瓶相似，大小亦相若。由于一九五四年故宫博物院陈万里先生以及后来浙江省古陶瓷研究者在调查和发掘位于浙江省慈溪市上林湖晚唐越窑遗址时，均曾发现过这种器物的残片，由此可以确定这件八棱瓶和法门寺唐代塔基地宫中出土的十四件秘色瓷，均为唐代晚期上林湖越窑产品。

# 故宫博物院藏 足径一七·八厘米 高五五・八厘米口径一七・八厘米 文物级别：一级品 北朝青釉莲花尊

南北朝时期，由于南、北方青瓷在配制胎、釉所用原料方面均有不同，致二者呈色和质感亦有区别。南方青瓷釉色青翠，北方青瓷玻璃质感较强。

此莲花尊为一九四八年河北省景县封氏、祖氏墓群出土的四件莲花尊之一。其形体高大，气魄雄伟，集塑贴、模印、雕刻等多种装饰技法于一体，纹饰华缛精美，令人叹为观止。景县出土的四件莲花尊目前故宫博物院收藏其中两件，中国国家博物馆、河北省博物院各收藏有一件。另外，在山东淄博、山西太原、江苏南京、湖北武汉等地均出土过南北朝时期的青釉莲花尊，且南北方出土的莲花尊呈现出不同的胎釉特征，说明南北朝时期，我国南北方瓷窑均烧造过此类产品。

唐三彩马文物级別：一级品高七六·五厘米长七七厘米故宫博物院藏

“唐三彩”是唐代多色釉陶的简称。其釉以氧化铅作主要助熔剂，以铜、铁、钴、锰等金属的氧化物作主要着色剂。先将胎体入窑经约一千至一千一百摄氏度素烧施釉后再入窑经约八百至九百摄氏度釉烧，烧成后，釉面即呈现深浅不同的绿、蓝、黄、褐、白、黑等色。当烧成达到釉层熔融状态时，各种颜色的釉相互浸润交融，呈现斑驳陆离的视觉效果，给人以富丽堂皇、变化万千之美感。

“唐三彩”的造型主要有盘、碗、杯、灯、枕、罐和各种人物俑、动物俑等。特别是骆驼、马、文官、武官、天王、武士、胡人、仕女、镇墓兽等各种俑，造型比例准确，形象生动传神，堪称代表“唐三彩”艺术成就的典型器物。

花釉系指在黑釉、黄釉、天蓝釉或茶叶末釉等底釉上用点、绘、淋、涂等方法装饰月白釉或天蓝釉，烧成后釉面交融浸润呈现变化莫测色彩的一种装饰釉。唐代文献称之为“花瓷”。它是唐代北方陶瓷工匠的重要发明，产地有河南、河北、山西、陕西等。其中以河南境内的花瓷窑数量最多，产量也最大。花瓷造型见有盘、碗、罐、执壶、腰鼓等。

腰鼓是唐代流行乐器之一。河南鲁山窑烧造的花瓷腰鼓颇为著名，唐人南卓《羯鼓录》对其有记载。此展品为现存唯完整的唐代花瓷腰鼓。

定窑遗址位于今河北省曲阳县，因曲阳县在北宋隶属定州管辖，故这里的瓷窑被称作“定窑”。定窑主要烧造白瓷，兼烧黑釉、酱釉、绿釉瓷，分别被称作“黑定”“紫定”“绿定”。始烧于唐代.兴盛于北宋、金代。北宋时期曾进行工艺改革，大量采用“覆烧”工艺，致使产量激增。定窑白瓷除光素者以外，还常以印、刻、剔、划、描金等技法进行装饰。尤以印花装饰最具特色，构图严谨，图案清晰，题材广泛，水平居宋代各窑瓷器印花装饰之首。定窑曾为宫廷和官府烧造贡瓷，署有刻划“官”“新官”“五王府“尚食局”“尚药局”等铭文者，均为宫廷和官府用瓷。

此枕作孩儿伏卧于榻上状，以孩儿脊背作枕面，是北宋定窑白瓷中的名品。据清宫造办处档案记载，乾隆皇帝于乾隆三十八年至四十年(一七七三年～一七七五年)曾多次提看“定瓷娃娃凉枕”，并下令为其配制木座、锦垫，可见其对孩儿枕的喜爱。而在乾隆皇帝咏定窑瓷器的御制诗中，也以咏孩儿枕为最多，共计十一首。

北宋 汝窑淡天青釉三足樽式炉文物级别：一级品高一二·九厘米口径一八厘米底径一二·八厘米故宫博物院藏

一般所称的“汝窑”，系指北宋徽宗时期专门为宫廷烧造瓷器的瓷窑，其遗址位于今河南省平顶山市宝丰县大营镇清凉寺村。因宝丰县在北宋归汝州管辖，故设在这里的瓷窑被称作“汝窑”。汝窑为宫廷烧造的青瓷，极为讲究，胎呈香灰色，釉呈淡天青色，釉面多开有细碎的片纹，俗称“冰裂纹”。器物造型规整，见有盘、碗、盏、钵、洗、碟、尊、瓶、樽式炉、盏托、出香(香炉)、壘子(方盒)等。因多采用“裹足支烧”，致使器物外底多留有细小支钉痕，俗称“芝麻挣钉”。绝大多数器物都光素无纹饰，极少数有刻划或印花装饰。釉色随造型线条的转折，呈现浓淡深浅变化，颇具韵味，具有很高的审美价值。汝窑青瓷是中国古代文人审美达到顶峰时的产物，历来被推为宋代瓷器之冠。

已知传世汝窑三足樽式炉仅三件，现分别收藏于故宫博物院、英国伦敦大维德基金会和美国辛辛那提艺术博物馆。

钧窑遗址位于今河南省禹州市原禹县城北门内的钧台与八卦洞附近，故亦称钧台窑、八卦洞窑。钧窑瓷器以釉装饰闻名于世，主要有天蓝釉、月白釉、天蓝釉加铜红斑、窑变釉等四种。其中最为人称道的是瑰丽异常的铜红窑变釉，这种釉是在青釉上施铜红釉，因铜红釉中还混杂其他着色金属氧化物，故烧成后釉色变化丰富，色彩绚烂，红、蓝、月白、灰紫等色交相辉映，别具神韵。钧窑瓷器可分为官钧和民钧两大类，官钧窑瓷器的造型主要有出戟尊、花盆、花盆托等，器物外底均刻划汉写数目字，从“一”到“十”均有，说明每套有十个型号。研究发现，数字越大，器物尺寸越小。关于官钧窑瓷器的年代学术界也有人认为不是北宋，而是元代末年至明代初年。

据南宋文献记载，宋代宫廷曾在都城附近设置过三个官窑，即北宋徽宗宣和、政和年间在汴京(今河南省开封市)设立的“北宋官窑”(亦称“大观窑”)和南宋朝廷在杭州附近先后设置的“修内司官窑”(亦称“内窑”)和“郊坛下官窑”。

目前学术界对有关北宋官窑和南宋修内司官窑的一些问题尚存争议。南宋郊坛下官窑遗址已于二十世纪初在杭州乌龟山麓被发现，一九五六年浙江省文物管理委员会对该窑址进行过局部考古发掘，出土一批瓷片和窑具标本。一九九六年位于杭州凤凰山的老虎洞窑遗址被发现，后经过正式考古发掘，获得大量瓷片和窑具标本，有学者认为老虎洞窑即文献记载的修内司官窑，亦有学者持不同观点。

从传世品和窑址出土瓷片标本看，宋代官窑瓷器的造型多为瓶、尊、壶、樽、炉、壘子、花盆、盏托、洗、碗、盘、杯等。胎体较薄，一般呈铁黑色或黑灰色;釉层较厚，釉面多有大开片纹，釉色多呈粉青色，如冰似玉，宛若天成。此瓶仿汉代铜壶式样，造型仿古是官窑瓷器造型的重要特征。

一二七八年，即元王朝统一中国的前一年，元朝廷即在景德镇设立专门负责烧造官府用瓷的机构“浮梁瓷局”，全国最优秀的制瓷工匠得以向景德镇集中，为景德镇制瓷业的迅速发展奠定了人才基础。而高岭土的发现和使用，则使景德镇的瓷胎由单一的瓷石改为瓷石加高岭土的“二元配方”，成为景德镇瓷业发展的一个新里程碑。元代景德镇窑成功烧造出青花、釉里红、卵白釉、蓝釉瓷等新品种，显示出非凡创造力，致使全国陶瓷生产中心逐渐向景德镇转移。

这里所说的哥窑系指传世哥窑,其遗址至今尚未被发现，学术界曾有诸多说法，目前比较一致的看法是哥窑遗址有可能在杭州凤凰山麓。从目前主要收藏在故宫博物院和台北故宫博物院的原清宫旧藏哥窑瓷器看，其造型主要有盘、碗、杯、洗、瓶、壶、炉、罐等，年代一般认为是南宋。器物胎体多呈灰黑色，釉面润泽如酥，釉色有青灰、炒米黄等。釉层较厚，釉面常开有大小两种纹片，大片纹呈灰黑色、小片纹呈黄褐色，俗称“金丝铁线”。片纹系因釉的膨胀系数大于胎的膨胀系数所致，釉面开裂本属制瓷工艺缺陷之一，但却被陶工巧妙利用，控制在一定范围内，形成错落有致、别具一格的片纹釉装饰。

# 故宫博物院藏 足径二四·一厘米 通高三三·二厘米 文物级别：一级品 明嘉靖 五彩鱼藻图盖罐口径一九·五厘米

![](清光绪鱼缸及画样、同治大婚用瓷_images/c01_ac1d9073dc3c3d9c457941de2847.jpg)

五彩是瓷器彩绘技法之一，可分为两大类:一类是纯釉上五彩;另一类是釉下青花和釉上诸彩相结合的青花五彩。所用釉上彩料多透明，因采取单线平涂法施彩，致使图案无浓淡深浅层次变化。其彩烧温度在八百至一千摄氏度左右。常见釉上彩料有红、草绿、孔雀绿、黄、紫、黑等。明代景德镇御窑五彩瓷器约始烧于明初，明代中期亦有少量烧造，至明代晚期嘉靖、隆庆、万历时期颇为流行。

从广义上说，斗彩瓷器也是釉下青花与釉上诸彩相结合的一种彩瓷，属于青花五彩之范畴。但二者又有区别。斗彩强调的是先在已做好的生坯上用青花料双钩图案轮廓线，或在此基础上描绘图案局部，施透明釉经高温烧成后，再在釉上按青花轮廓线填涂红、黄、绿、紫等各种色彩。而青花五彩则是先在做好的生坯上以青花料画图案局部，施透明釉经高温烧成后，再在釉上勾线，并施以红、黄、绿、紫等各种色彩，凑齐整个图案。

# 故宫博物院藏 足径七·三厘米 高一〇·五厘米 口径五·五厘米 文物级别：一级品 明成化斗彩海水天马图罐

斗彩属于瓷器装饰技法之一。系指先在成型后的胎体上以青料双钩图案轮廓(有的还在此基础上画出图案局部)，经高温烧成后，再在釉上按烧成温度高低依次施以各种釉上彩，然后入炉经一次或多次低温(按温度由高到低)焙烧而成。因纹饰系由釉下青花与釉上诸彩拼凑而成，各种色彩争奇斗艳，故曰“斗彩”。

斗彩技法萌发于明代宣德朝，发展于正统至天顺朝，成熟于成化朝，正德、嘉靖、隆庆、万历等朝均有烧造，其中以成化斗彩瓷器最负盛名。成化斗彩瓷器造型小巧.常见瓶、罐、盒、盘、碗、杯、碟等品种，釉质温润如玉，色彩搭配协调，绘画工艺精湛，颇显隽秀典雅。

此罐因外底署“天”字款，俗称“天字罐”是成化斗彩瓷器中的名品。

## 故宫博物院藏 足径一七·五厘米 高三二厘米口径一九厘米 文物级别：一级品 明弘治浇黄釉描金弦纹牺耳尊

中国传统低温黄釉是一种以氧化铁为着色剂、以氧化铅为助熔剂的单色釉。明代自洪武至万历朝，黄釉瓷的烧造从未间断。从传世品及出土物看，宣德、成化时期的黄釉瓷器已很精致，但以弘治、正德时期的黄釉瓷器受到的评价最高。特别是弘治黄釉瓷器，颜色纯正，色调均匀一致，釉面平整，犹如涂抹的鸡油，恬淡娇嫩，透彻明亮，达到历史上最高水平。由于这种黄釉瓷器的施釉方法是将釉浆直接浇在素烧过的涩胎上，故称“浇黄釉瓷”。弘治浇黄釉瓷因颜色娇嫩，故人们又赋之以“娇黄”之美称。

明代黄釉瓷器除用作御用餐具外，据文献记载还被用作方丘（地坛）的祭祀用器。

此盘内、外和圈足内均施白釉，足底无釉。盘内底和外壁均以矾红彩书写阿拉伯文，外底以矾红彩书写阿拉伯文、波斯文。内底四周四个阿拉伯文释义为“清高尊大的真主说”；内底中心的阿拉伯文摘自《古兰经》，释义为“你不要把手完全伸开，以免你变成悔恨的受责备者”。盘外壁的阿拉伯文释义为“清高尊大的真主说，谁做了尘埃大的好事,(或者)谁做了尘埃大的坏事，他(真主)都会看到，这就是行好的人的报答”。外底三行文字中，中间一行为阿拉伯文，上下两行为波斯文，联起来释义为“迪麦尼可汗即阿曼苏来曼沙”。(参见李毅华《两件正德阿拉伯文波斯文瓷器兼谈伊斯兰文化的影响》，《故宫博物院院刊》一九八四年第三期)

明德化窑何朝宗制白釉观音坐像文物级别：一级品高二八厘米 底径一三·三厘米故宫博物院藏

福建德化地区陶瓷烧造历史，最迟可上溯至商周时期的原始瓷，唐、宋、元时期瓷器生产快速发展，盛烧于明、清两代。德化窑素以烧造独具特色的白瓷而名扬天下。德化白瓷胎质洁白细腻，釉质乳白似脂，胎釉浑然一体，透光度极佳，深受人们喜爱，行销国内，远销海外。国人誉之“猪油白”“象牙白”;法国人则赞其为“鹅绒白”“中国白”。产品见有仿青铜器造型的炉、觚、鼎、尊等，也有不少著名的瓷雕作品，多为观音、达摩等宗教人物，有些塑像的背部戳有工匠印记，如“何朝宗”“林朝景”“陈伟”“张寿山”等。其中何朝宗为一代大师，其作品声誉最重，所作各种佛教、道教人像，神态生动，栩栩如生，深受人们喜爱，并曾被用作贡品进贡朝廷。

清康熙 蓝地珐琅彩缠枝牡丹纹碗 文物级别：一级品 高五·二厘米口径一一厘米 足径四·四厘米 故宫博物院藏

珐琅彩是康熙晚期受从欧洲进口的铜胎画珐琅影响而新创的一种瓷器釉上彩装饰技法。雍正六年(一七二八年)以前，珐琅料需从欧洲进口，从雍正六年开始，清宫造办处已能自炼珐琅料，而且色彩种类超过进口料。烧造珐琅彩瓷器所用白瓷胎系由景德镇御窑厂提供，运送到紫禁城后，由造办处指定宫廷画师和宫廷写字人描绘纹饰、题写诗句和款识，再在造办处进行彩烧。

![](清光绪鱼缸及画样、同治大婚用瓷_images/c01_f150d1e18c48e3fe12c4a751c67b.jpg)

康熙时期的珐琅彩瓷器处于初创期，多以胭脂红、淡黄和蓝色作地，其色彩、纹饰等皆与同时期铜胎画珐琅器相似。

这件白釉观音塑像釉色洁白如脂、姿态端庄稳重、衣纹潇洒自然，代表明代德化窑白瓷的高超水平。

![](清光绪鱼缸及画样、同治大婚用瓷_images/c01_d1fec9ed9e4683141bcdd9c6223c.jpg)

![](清光绪鱼缸及画样、同治大婚用瓷_images/c01_9a92aa5e84b74c6bbe611549584d.jpg)

珐琅彩瓷器以雍正、乾隆时期的产量最大，制作工艺精湛、色彩华美瑰丽，乾隆朝以后即少有制作。乾隆时期，宫中收藏的珐琅彩瓷器曾集中存放在端凝殿，据记载有四百多件。按照宫廷档案记载和珐琅彩瓷器原盛匣之标识，得知清代宫廷称珐琅彩瓷器为“瓷胎画珐琅”。

雍正、乾隆朝的珐琅彩瓷器逐渐脱离铜胎画珐琅影响，形成集诗、书、画、印于一体的文雅风格，是中国古代彩瓷工艺臻达顶峰时期的产物。那些形状看似普通的珐琅彩盘、碗等，已摆脱日常生活中的实用功能，成为能给人视觉带来美的享受的艺术珍品。

此碗外壁以黄地珐琅彩绘怪石兰花图并配以诗句装饰。一面以黑彩皴绘怪石，其后生一丛兰花，兰叶自然舒展，兰花盛开，花丛左侧长出一棵灵芝。另一面以黑彩题写行书体“云深琼岛开仙径，春暖芝兰花自香”七言诗句，首钤胭脂红彩篆体“佳丽”长方形朱文闲章，末尾钤胭脂红彩篆体“金成”“旭映”两枚方形朱文闲章。外底署图章式蓝料彩宋体“雍正年制”四字双行外围双方框款。

此瓶外壁自上而下装饰的釉、彩多达十五层。所使用的釉上彩装饰品种有金彩、珐琅彩、粉彩等；釉下彩装饰品种有青花；还有釉上彩与釉下彩相结合的斗彩。所装饰的釉有仿哥釉、仿汝釉、仿官釉、松石绿釉、窑变釉、粉青釉、祭蓝釉、酱釉等。主题纹饰在瓶的腹部，为祭蓝釉描金开光粉彩吉祥图案，共十二个开光，其中六幅为写实图画，分别为“三阳开泰”“吉庆有余”“丹凤朝阳”“太平有象”“仙山琼阁”“博古九鼎”等。另六幅为锦地“卍”字、蝙蝠、如意、蟠螭、灵芝、花卉等，分别寓意“万”“福”“如意”“辟邪”“长寿”“富贵”。瓶内及圈足内均施松石绿釉，外底中心篆体“大清乾隆年制”六字三行款。

这件大瓶，因集各种高温、中温、低温釉、彩于一身，故素有“瓷母”之美称，集中体现了当时高超的制瓷技艺。

粉彩“御窑厂图”螭耳瓶瓶身纹饰展开图

粉彩属于釉上彩瓷器中的一种，系使用珐琅料按照西洋绘画技法描画纹饰的瓷器，故曾被称作“洋彩”。它是康熙晚期在烧造五彩瓷器的基础上，受珐琅彩工艺的影响，由景德镇制瓷工匠创烧的釉上彩瓷新品种。较之五彩，粉彩所表现的物象，粉润柔和，细致入微，富有层次感，更显生动自然，故粉彩亦称“软彩”。

此瓶外壁通体以粉彩描绘清代景德镇珠山御窑厂实景图，以御窑厂内倚山而建的“御诗亭”为中心，左右东西辕门上各挂一面黄色大旗，旗上以黑彩书写“御窑厂”三字，两侧白墙黑瓦，有回廊、洞门。正中的高大厅堂内，几位监官在商量事情。厂内匠人各司其职，专心劳作，可以看出有开采原料、送料、拉坯、利坯、施釉、画坯、烧窑、出窑、装运等各道工序。所使用的彩料有红、黄、绿、紫、蓝、黑、金等，所绘人物共有六十一个。这件大瓶上的图案真实反映了清代道光时期景德镇御窑厂的生产场景，印证了有关文献记载的御窑厂建制、分工、生产等情况，可用作研究当时景德镇御窑厂生产状况的珍贵实物资料。

清乾隆 浇黄釉仿古铜纹簠

簠最早是中国古代宴飨时盛放稻、梁的器具，后用于祭祀，成为礼器。《周礼·地官·舍人》注:“方曰簠，盛稻粱器。”《礼记·乐记》载:“簠簋俎豆，制度文章，礼之器也。”《周礼·舍人》载:“凡祭祀共簠簋。”祭祀时，簠、簋总是同时出现。清代祭器根据不同材质、颜色区别其在祭祀中的不同功用和使用场合。据《皇朝礼器图式》记载，簠为乾隆十三年(一七四八年)钦定祭器，面为夔龙纹束为回纹，足为云纹，两耳附以夔龙。盖上有棱，亦附以坛龙耳。
