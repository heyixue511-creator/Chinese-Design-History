# 汁靈國中造再

靈效異常一時風行中國二十二省
凡腦筋不強者無不視爲秘寶無論
老少男婦春夏秋冬服之皆有奇效
中國前數年軍學界景象何等委員
不振自經補腦汁輸入以後服此者
人人知愛國人人知保種智慧日長
思想日新未始非此汁再造之功中
國人欲強國強種舍此固別無造命
之靈藥矣余常服此汁一切思想智
慧迥異往日故特登報聲明以告我
四萬萬之同胞速速強腦
